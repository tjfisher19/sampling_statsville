Sampling the town of Statsville

Introduction

Video Introduction

Statsville is a quaint fictional hamlet that is nestled in the foothills of the Regression Mountains with a beautiful view of Lake Median. The population is quite small as only 100 residents between the ages of 13 and 59 live in Statsville. The layout of the town is a basic square grid with 20 unique roads – conveniently named with first letters A to T.

The Mean Diner is looking to increase business and has decided to start advertising on social media. Before investing into their campaign, management wishes to know what sort of effort is required. In particular, management needs to know how many social media apps each resident typically uses so they can spend their advertising dollars wisely.

A diagram below displays all 100 residents along with an icon for each social media site (e.g., TikTok, YouTube, Instagram) the resident uses regularly. For example, Person 22 is a female with Brown Eyes, is 66.9 inches tall, and regularly uses 8 social media sites as appears 8 times. Another grid displays an image of those same residents stratified by their respective age groups (teenagers, twenty-somethings, residents in their 30s, in their forties and fifties). Lastly, a final figure includes an image of each resident grouped by the street in which they live.

We will use this population to explore different sampling techniques to help the Mean Diner estimate the average number of social media apps for residents in Statsville.

Simple Random Sample

When little knowledge is known about the distribution of the population, the standard approach is to use a Simple Random Sample. A simple random sample is like playing a game of bingo or the lottery – each person (or number) has an equal chance of being selected. In lieu of a bingo cage or lottery spinner, we can use the computer to generate the sample.

Simple Random Sample Video

Use the below random number generator to select residents (by their ID number) to be sampled.

viewof count = Inputs.number([0, 100], {
  value: 10,
  step: 1,
  label: "Sample size:"
})

viewof runButton = Inputs.button("Generate Simple Random Sample")

html`<div style="display: flex; flex-direction: column; gap: 20px;">
  ${viewof count}
  ${viewof runButton}
</div>`


people = Array.from({ length: 100 }, (_, index) => index + 1);


randomSample = {
   runButton;
   return d3.shuffle([...people]).slice(0, count);
}
// 3. Display the numbers beautifully
{
  if (runButton === 0) {
  return md`**Click the button to generate a sample**`;
  } else {
  return md`**Your Sample:** Persons ${randomSample.sort((a, b) => a - b).join(",  ")}`
  }
}

Systematic Sampling

Systematic sampling is a technique where a researchers select members of the target population at regular or fixed intervals after choosing a random starting point. As an example, you may sample every \(n\)th person.

Systematic Sampling Video

Use may use the random number generator to randomly select one of the first 10 residents to start the systemic sampling procedure.

viewof rollDie = Inputs.button("🎲 Roll 10-sided Die")

html`<div style="display: flex; flex-direction: column; gap: 20px;">
  ${viewof rollDie}
</div>`


// 3. Shuffle and slice to get your random sample
// 1. Define your data array

randomDie = {
   rollDie;
   return Math.floor(Math.random() * 10) + 1;
}
// 3. Display the numbers beautifully
{
  if (rollDie === 0) {
  return md`**Click the button to roll the die**`;
  } else {
  return md`**Your Die Roll:** Person ${randomDie}`
  }
}

Stratified Sampling

Here the population is grouped by age and a quick look shows that distribution of social media apps is not the same across all age groups (visually it appears residents in their 20s have more social media apps than residents in their 50s). It is possible that a simple random sample would not truly be representative of the population.

Population grouped by Streets

This diagram shows the 100 residents grouped by the street in which they live.

Cluster Sampling

Here, the residents have been grouped by the street of their home. Compared to the grouping by age, it is not as clear if there are patterns in the distribution social media apps by street. This type of segmentation of the population leads to a method known as Cluster Sampling – randomly choose clusters (in this case Streets) and sample all residents that live on a specific street.

Cluster Sampling Video

Use the Applet below to generate a Cluster Sample.

viewof street_count = Inputs.number([0, 20], {
  value: 2,
  step: 1,
  label: "Number of Clusters:"
})

viewof runStreet = Inputs.button("Generate Sample of Clusters")
streets = ["Apple Avenue", "Beech Street", "Chestnut Street", "Dogwood Drive", "Elm Street","Falcon Avenue", "Goetta Way", "High Street", "Indigo Avenue", "Jambalaya Drive", "Kookaburra Court", "Lemon Lane", "Maple Street", "Narwhal Alley", "Oak Street", "Poplar Street", "Quinoa Way", "Ramblin Road", "Sycamore Street", "Truffula Road"]

streetSample = {
   runStreet;
   return d3.shuffle([...streets]).slice(0, street_count);
}

{
  if (runStreet === 0) {
  return md`**Click the button to generate a sample of clusters**`;
  } else {
  return md`**Streets Chosen to Sample:** ${streetSample.sort((a, b) => a.localeCompare(b)).join(",  ")}`
  }
}
